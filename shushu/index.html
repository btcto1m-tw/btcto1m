數數是什麼

數數是一個「記錄型」的個人成長追蹤 App。它不問「你做了沒」，只記「你做了多少」。 今天做了 10 下就記 10，明天做 11 就記 11 —— 目標不是你設的，是曲線自己長出來的。

怎麼用（5 秒完成）

打開 App →點一個項目→輸入今天做的數字→關掉。報表會自己長出來。 項目名稱與單位都由你自己定（例如「伏地挺身 / 下」「閱讀 / 頁」「冷水澡 / 秒」）。 同一天記多次會自動累加；往下捲即是該項目的折線圖、月曆熱力圖與摘要數字。

資料與隱私

所有資料只存在你自己的裝置上，不上傳伺服器、沒有帳號、不需連網。 你可以在「設定」裡隨時匯出 JSON 備份，或匯入還原。

What is shushu

shushu is a record-first personal growth tracker. It doesn't ask whether you did it — it records how much you did. Did 10 today, log 10; do 11 tomorrow, log 11. You don't set the goal — the curve grows it for you.

How to use it (5 seconds)

Open the app → tap an item → type today's number → close. The charts grow on their own. You define every item name and unit yourself (e.g. "push-ups / reps", "reading / pages", "cold shower / seconds"). Multiple entries on the same day add up automatically; scroll down on an item to see its line chart, calendar heatmap, and summary numbers.

Data & privacy

All your data stays only on your own device — nothing is uploaded, there is no account, and no network connection is required. You can export a JSON backup, or import to restore, anytime from Settings.
